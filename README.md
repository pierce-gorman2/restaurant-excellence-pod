# Restaurant Excellence Podcast Starter

This is a lightweight starter website for **Restaurant Excellence**, currently scoped as a **podcast hosting platform** for:

- DHC of Kansas
- DHC of San Antonio yes
- DHC of Nashville

## What this includes

- A polished homepage
- Market sections for the three launch markets
- Filterable podcast episode cards
- Easy-to-edit episode data file
- A clear structure Codex can expand later

## Files

- `index.html` — homepage markup
- `styles.css` — site styling
- `script.js` — market filter interaction
- `data/episodes.js` — sample episode data
- `PROJECT_BRIEF.md` — instructions for Codex to continue the build

## How to use

1. Upload this folder into Codex.
2. Tell Codex to use `PROJECT_BRIEF.md` as the product spec.
3. Ask Codex to convert this into the framework you want later if needed (Next.js, Astro, etc.).

## Suggested Codex prompt

Use the files in this folder as the starting point. Improve the design and structure, but keep the core purpose the same: Restaurant Excellence is currently only a podcast platform for DHC of Kansas, DHC of San Antonio, and DHC of Nashville. Make it feel premium, leadership-focused, modern, and easy to expand later into a bigger media and training platform.
